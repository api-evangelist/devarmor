DevArmor provides AI‑powered continuous threat modeling and security design tools for development teams. Its platform automates security reviews, generates living threat models, and enforces guardrails across code, design and architecture. Targeted at engineering, security, fintech, healthtech and media teams, DevArmor offers real‑time design feedback, compliance assistance, and integration with SSO providers. The service includes a documentation portal, pricing calculator, blog, and support resources to help organizations embed security into their development workflows.

**Areas:** Company · Security · AI · Threat Modeling · DevOps

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for DevArmor: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
